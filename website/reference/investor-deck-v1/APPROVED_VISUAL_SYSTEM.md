# Biella Investor Deck — Approved Visual System v1

Status: owner-approved visual direction from the current ChatGPT production session.

## Visual language
- 16:9 cinematic dark presentation system.
- Near-black/navy foundation, cyan accent lines, controlled mint/blue/amber/violet metrics.
- Large white investor-readable headings with consistent left alignment and generous safe margins.
- High-contrast opaque/translucent content panels over restrained cinematic backgrounds.
- Metric cards, simple diagrams, disciplined spacing, no text over uncontrolled bright detail.
- Financial pages remain dense, structured, professional, and diligence-readable.
