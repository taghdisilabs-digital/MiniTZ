## 4. Website story spine

### 4.1 Core public thesis

Biella is a project-neutral AI production and execution engine for turning goals into durable, inspectable production work. It organizes objectives into tasks, runs, graphs, capabilities, resources, artifacts, events, evidence, and scoped knowledge so work can continue beyond one chat, process, model, host, or temporary workspace.

The public story is not "another chatbot" and not "a game studio website only." The story is an AI production engine plus a project universe that demonstrates why durable execution, source identity, scoped memory, replaceable resources, validation, and publication evidence matter.

### 4.2 Engine story

Biella Engine should be described as under active durable integration. Current Engine source records show `46 / 51 durable` with the next Engine repair frontier at `P3-11 — Image Production, Editing, Compositing and Texture Pack`; remaining incomplete boundaries include `P3-11`, `P3-12`, `P3-13`, `P3-14`, and `P4-06`.

Allowed Engine message:

> Biella Engine is being built as a durable AI production engine that can plan work, route semantic capabilities to replaceable models/tools/machines, preserve evidence, recover from failures, and deliver source-backed outputs across software, games, media, and production workflows.

Required qualifier:

> The Engine is not yet presented as a finished public product. Website pages must use the current `03/04` state records and task ledger before claiming live capability status.

### 4.3 Games story

Biella Games is a separate project scope using Biella Engine concepts where useful, but it is not the Engine itself. The accepted direction is a realistic, physically coherent, highly detailed AAA third-person real-time game project. The accepted runtime baseline is `Unreal Engine 5.8.2`, C++, Windows PC x64 first, DirectX 12 / Shader Model 6, UnrealBuildTool and Unreal AutomationTool.

- Unreal project source exists in `patrickminitz-web/biella-games` at commit `5f4304db91fc214138fb3b462545681db8685b20` / tree `c375a14c5ac93238737811d93d9197c6d5e4df41`;

- the website runtime-media lane has zero accepted game runtime media;
- no playable game claim is permitted until `GAME-00-BOOTSTRAP` and later gameplay rows satisfy their real runtime evidence contracts.

Allowed Games message:

> Biella Games is the project-specific game lane: a real-time Unreal Engine 5.8.2 third-person game direction with source bootstrap underway and strict evidence rules that reject screenshots, prerenders, mock HUDs, or website demos as gameplay completion.
