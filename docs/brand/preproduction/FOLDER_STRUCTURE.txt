RULES
-----
1. The ten root control files remain at package root exactly as named.
2. Authoritative logo geometry lives only at 02_LOGO/MASTER_LOGO_GEOMETRY.svg.
3. Editable 3D/motion/project sources stay under SOURCE/ or EDITABLE/ lanes.
4. Interchange exports never replace native editable source.
5. Final derivatives live only under 11_EXPORTS/ or the domain EXPORTS/ lane.
6. QA evidence stays under 12_QA/ and is not mixed with production source.
7. Release candidates stay under 13_DELIVERY/ until validated.
8. Caches, autosaves, temporary renders, node_modules, generated build caches,
   and application scratch data are not part of this package.
9. Both Codex and Biella must use these exact paths rather than creating
   parallel package roots.
10. If a path must change, update FOLDER_STRUCTURE.txt, ASSET_MANIFEST.json,
    and VERSION_LOG.md in the same approved revision.
