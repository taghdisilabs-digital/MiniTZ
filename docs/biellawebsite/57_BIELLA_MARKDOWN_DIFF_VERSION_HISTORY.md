# 57 — Markdown Diff & Version History

## Purpose
A precise document revision surface for comparing Markdown/text versions and understanding exactly what changed, when, and why.

## Required detailed content
1. **Revision timeline** — author/source, timestamp, revision ID, branch or Drive revision, and status.
2. **Side-by-side diff** — synchronized old/new panes with line numbers and section navigation.
3. **Unified diff mode** — compact patch-style view for rapid engineering review.
4. **Section-aware comparison** — headings, paragraphs, lists, tables, code blocks, links, and front matter.
5. **Change statistics** — added/removed/changed lines, words, tokens, headings, links, and code blocks.
6. **Restore/revert controls** — choose target revision, preview result, and preserve current version identity.
7. **Anchored review threads** — comments/replies tied to exact changed text.
8. **Semantic-change summary** — separate meaning-level changes from literal text changes.
9. **Provenance panel** — original file, source repository/Drive object, revision, digest, and author/source.
10. **Conflict resolver** — show concurrent edits and merge choices without hiding conflicts.
11. **Search changed text** — filter by file section, contributor, date, or change type.
12. **Export change report** — patch, Markdown report, or revision manifest.

## BIELLA VISUAL LOCK
Transparent background. Graphite/navy surfaces. Violet primary, cyan secondary. Green additions, red removals, amber conflicts only. Thin precision borders and restrained glow.

## Acceptance
The user can prove exactly which revision introduced a change, understand its semantic effect, and restore safely.
