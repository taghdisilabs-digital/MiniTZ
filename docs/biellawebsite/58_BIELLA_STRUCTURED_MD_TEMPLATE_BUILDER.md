# 58 — Structured Document / Markdown Template Builder

## Purpose
A reusable template system for Biella prompts, specifications, ADRs, task reports, runbooks, release notes, project instructions, website briefs, and other structured Markdown.

## Required detailed content
1. **Template library** — grouped by document purpose with version, owner, and compatibility status.
2. **Section/block palette** — headings, metadata, tables, checklists, code, diagrams, result blocks, evidence, callouts, and references.
3. **Variable/schema editor** — field names, types, required/optional status, defaults, constraints, and descriptions.
4. **Live Markdown editor** — source view with syntax highlighting and structural outline.
5. **Rendered preview** — realistic final-document view with responsive layout.
6. **Conditional sections** — explicit optional blocks with visible conditions; no hidden behavior.
7. **Example-data preview** — populate template with sample values before publishing.
8. **Validation panel** — missing placeholders, duplicate sections, invalid variables, broken references, malformed front matter.
9. **Template dependency graph** — includes/imports, inherited fragments, and version compatibility.
10. **Version history** — revisions, changelog, superseded templates, and migration notes.
11. **Usage registry** — where each template is currently used.
12. **Export** — `.md`, JSON schema, template pack, or website-content source.

## BIELLA VISUAL LOCK
Transparent background. Graphite/navy. Violet dominant. Cyan secondary. Semantic status colors only. Compact professional component-builder layout with thin technical borders.

## Acceptance
Templates produce predictable, inspectable Markdown and never silently introduce project policy or hidden execution rules.
