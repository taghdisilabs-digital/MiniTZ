# 60 — Document Export & Publishing

## Purpose
A final document delivery workspace for converting accepted Markdown/docs into website pages, HTML, PDF, DOCX, reports, documentation bundles, and publication artifacts.

## Required detailed content
1. **Source selector** — exact source document, revision, digest, project, and acceptance status.
2. **Output format matrix** — Markdown, HTML, PDF, DOCX, static-site page, JSON/evidence bundle.
3. **Theme/style selector** — Biella website presets, documentation themes, print profile, syntax theme, spacing scale.
4. **Asset/link resolver** — images, diagrams, code highlighting, attachments, anchors, internal and external links.
5. **Publication preview** — desktop/tablet/mobile plus print preview.
6. **Build/export queue** — progress, current stage, warnings, errors, output size, and elapsed time.
7. **Validation panel** — broken links, missing assets, malformed Markdown, inaccessible references, invalid metadata.
8. **Metadata and SEO** — title, description, canonical path, social preview, version, author/owner, robots/indexing setting.
9. **Destination controls** — local artifact, Google Drive archive, website build directory, release package, or documentation bundle.
10. **Versioning/release note** — publication version, source revision, changelog, superseded output.
11. **Delivery receipt** — output digest, source digest, timestamp, destination, tool/runtime identity, and status.
12. **Rollback/re-publish** — select prior accepted publication and regenerate from exact source.

## BIELLA VISUAL LOCK
Transparent background. Graphite/navy surfaces. Biella violet dominant. Electric cyan secondary. Semantic status colors only. Thin precision borders, subtle glass, restrained bloom.

## Acceptance
Every published document can be traced back to the exact accepted source revision and resulting artifact identity.
