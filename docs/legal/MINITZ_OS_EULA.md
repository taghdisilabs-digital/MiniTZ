## 22. Commercial Success Royalty

### 22.1 Per-Project Royalty-Free Threshold

Each MiniTZ Project is evaluated separately.

The first **US$500,000 of cumulative Gross Project Revenue** generated by each MiniTZ Project is royalty-free.

### 22.2 Royalty

After a MiniTZ Project exceeds US$500,000 in cumulative Gross Project Revenue, the project owner owes TaghdisiLabs.Digital:

**3% of Gross Project Revenue above US$500,000.**

The royalty applies only to the portion above the threshold.

### Example

If a MiniTZ Project generates US$700,000:

- first US$500,000: royalty-free;
- amount exceeding threshold: US$200,000;
- royalty: 3% × US$200,000;
- royalty due: **US$6,000**.

## 26. Royalty Reporting and Payment

### 26.1 Before the Threshold

No MiniTZ royalty report or royalty payment is required while a MiniTZ Project has generated US$500,000 or less in cumulative Gross Project Revenue.

### 26.2 First Report

When a MiniTZ Project first exceeds US$500,000, the project owner must submit its first royalty statement within **30 days after the end of the calendar quarter in which the threshold was exceeded**.

### 26.3 Ongoing Reports

After the threshold is exceeded, royalty statements are due quarterly.

Calendar quarters end:

- March 31;
- June 30;
- September 30;
- December 31.

Reports and corresponding payments are due within **30 days after the end of each calendar quarter**.
